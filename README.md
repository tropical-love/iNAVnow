# iNAVnow

한국 상장 ETF의 **지금 이 순간 iNAV(순자산가치)** 를 구성종목 실시간 시세로 계산해 보여주는 웹페이지입니다.
내 PC에서만 도는 로컬 서버라 가입도, 계정도, 외부 전송도 없습니다.

하루 한 번 갱신되는 공식 NAV나 장중에만 나오는 공식 iNAV와 달리
**미국 프리·정규장·애프터·주간거래(Blue Ocean)** 와 **국내 시간외**까지 반영합니다.

> 밤사이 미국장에서 담긴 종목이 10% 올랐어도, 증권사 앱의 NAV는 다음날 장이 열릴 때까지 어제 값 그대로입니다.
> 장 시작 전에 적정가를 미리 가늠하거나, 지금 시장가가 얼마나 비싸고 싼지(괴리율) 확인할 때 쓰세요.

**소스는 `server.js` 파일 하나입니다.** 외부 라이브러리를 쓰지 않아 `npm install`이 필요 없고,
설치 스크립트가 뭘 하는지 궁금하면 `manage.ps1`을 그대로 열어 보시면 됩니다.

## 안드로이드 앱

폰에서 쓰시려면 앱으로 설치하세요. 같은 계산을 **폰 안에서 직접** 합니다 — PC도, 서버도, 같은 와이파이도 필요 없습니다.

### ⬇ [inavnow.apk 내려받기](https://github.com/tropical-love/iNAVnow/releases/latest/download/inavnow.apk)

Android 8.0 이상. 스토어를 거치지 않는 설치라 **"출처를 알 수 없는 앱"** 허용을 한 번 물어봅니다
(설치를 실행한 앱마다 최초 1회). 소스와 빌드 방법은 [android/](https://github.com/tropical-love/iNAVnow/tree/main/android)에 있습니다.

포트폴리오·관심 목록은 기기 안에만 저장되고, 외부로 나가는 통신은 시세 조회뿐입니다.

## PC에 설치 (Windows)

### ⬇ [inavnow-pc.zip 내려받기](https://github.com/tropical-love/iNAVnow/releases/latest/download/inavnow-pc.zip)

1. [Node.js](https://nodejs.org) 설치 (18 이상, 20 권장)
2. 위 zip을 원하는 곳에 압축 해제
3. **`manage.bat` 더블클릭 → `1) 서비스 등록 + 시작`**
4. 브라우저에서 **http://localhost:3456**

등록·삭제는 Windows 작업 스케줄러를 건드리므로 관리자 권한이 필요합니다(그 동작에서만 UAC 창이 뜹니다).
등록하면 로그온할 때 자동으로 뜨고, 죽으면 1분 안에 스스로 살아납니다.

```
  iNAVnow 로컬 서버 관리

  서버   : 실행 중  (http://localhost:3456, PID 19320, 창 없음)
  자동시작: 켜짐 (로그온 시 시작 + 1분마다 생존 확인)
  등록방식: S4U — 창 없음

   1) 서비스 등록 + 시작   (관리자 권한 필요)
   2) 서비스 삭제          (관리자 권한 필요)
   3) 서버 시작
   4) 서버 종료            (자동 재시작도 중지)
   5) 브라우저로 열기
   0) 나가기
```

작업 스케줄러를 쓰고 싶지 않으면 폴더에서 `node server.js` 로 직접 띄워도 됩니다.

> **S4U / 콘솔 창**: 관리자 권한으로 등록하면 세션 0에서 돌아 콘솔 창이 아예 뜨지 않습니다.
> 권한이 없으면 `Interactive`로 등록되고 콘솔 창이 하나 뜹니다(동작은 같습니다. 그 창을 닫으면 서버가 꺼집니다).

## 계산 방식

```
iNAV = 기준NAV × (1 + Σ 비중 × (주수 × 현재가 × 환율 ÷ PDF평가액 − 1))
```

- **PDF**(설정단위당 구성종목 명세)는 운용사 공식 자료를 씁니다. 막히면 FunETF → 형제 ETF → 네이버 상위10 순으로 대체합니다.
- **환율 기준점은 PDF 평가금액에서 역산**합니다. 야후의 전일 종가는 외환 일봉 경계(23:00 UTC) 기준이라 "어제 한국장 마감" 시점과 어긋납니다(4일 전 값이 오기도 합니다).
- **기준 NAV가 하루 밀린 경우** 설정단위 좌수를 역산해 자동으로 보정합니다.
- **괴리율**은 국내 시간외 변동분만 제거해 ETF 종가와 시점을 맞춥니다.

### 추정하지 않는 경우

값을 만들어내는 대신 **KRX 공식 iNAV를 그대로** 보여줍니다.

- 레버리지·인버스·합성형 중 기초 ETF를 특정할 수 없는 상품 (PDF가 스왑·TRS·선물이라 실물 바스켓이 아닙니다)
- 코스피200·코스닥150 선물형 (실시간 선물 시세 공개 소스가 없습니다)
- 구성종목 시세를 하나도 구할 수 없는 상품 (인도·베트남 주식, 채권형 등)

## 화면 설정 (우측 상단 ⚙)

| 항목 | 설명 |
|---|---|
| 테마 | 자동(시스템) / 라이트 / 다크 |
| 목록 초기화 | 관심 목록 · 최근 조회 |
| 페이지 타이틀 | 기본 / 종목명 미표시 / 오피스 모드(파비콘·제목 변경) |
| 현재 iNAV 표시 | 탭 제목에 iNAV를 함께 표시 |

설정·관심 목록·최근 조회는 브라우저 `localStorage`에 저장됩니다(서버로 가지 않습니다).

## 내 포트폴리오

메인 화면 아래 **내 포트폴리오**에 보유 종목·평균단가·수량을 넣으면, 구성종목 실시간 시세로 계산한
**지금 이 순간의 평가금액**과 손익을 보여줍니다. 공식 NAV로 계산하는 증권사 앱과 달리 미국장·환율이 바로 반영됩니다.

- 첫 접속에 한 번 계산하고 이후 **5분마다** 자동 갱신합니다. 시각 옆 ↻ 버튼으로 즉시 다시 계산할 수 있습니다(진행률이 링으로 표시됩니다).
- 종목별 막대는 **현재가치 기준 비중**이라 가격이 움직이면 함께 움직입니다.
- 수량·평균단가는 이 브라우저의 `localStorage`에만 저장되고 **서버로 전송되지 않습니다**.
  (소스에 `/api/pf`를 쓰는 분기가 보이지만, 이 배포판에는 그 API를 제공하는 래퍼가 없어 항상 브라우저 저장으로 동작합니다.)

## 알아두실 점

- **추정치입니다.** 운용사 공식 iNAV가 아닙니다. 반영률이 100%가 아니면 미추적 종목을 추적된 바스켓의 평균으로 외삽하므로 오차가 생깁니다. 화면의 **반영률**을 함께 보세요. 투자 판단의 책임은 사용자에게 있습니다.
- **접속은 내 PC에서만 됩니다.** `127.0.0.1`에만 바인딩합니다. 같은 와이파이의 폰에서 보려면 `HOST=0.0.0.0 node server.js`로 띄우세요 — 단, **비밀번호가 없으므로 그 네트워크의 모두에게 공개**됩니다. 회사 네트워크에서는 권장하지 않습니다.
- **시세 출처**: 네이버(국내·목록·PDF 일부), Yahoo Finance(미국·일본·홍콩·중국, 프리·애프터), 토스(미국 주간거래), 각 운용사 사이트, FunETF. 모두 공개 엔드포인트를 개인 사용 수준으로 호출합니다. 갱신 주기를 무리하게 줄이면 차단당할 수 있으니 기본값(화면 10초 / 시세 30초 / 환율 15초)을 권합니다.
- **보이지 않는 탭도 갱신**합니다(제목의 iNAV를 보기 위한 로컬 전용 동작). 브라우저가 숨은 탭 타이머를 묶어 실제로는 약 1분 간격입니다.
- 외부 의존성이 없습니다. `npm install` 필요 없이 Node 내장 모듈만 씁니다.

## 파일

| 파일 | 용도 |
|---|---|
| `server.js` | 서버 전체. 외부 의존성 없음, Node 18+ |
| `test.js` | 회귀 검사 — `node test.js` (네트워크 없이 돕니다) |
| `manage.bat` / `manage.ps1` | 관리 메뉴 — 등록·삭제·시작·종료·상태 |
| `start.bat` / `stop.bat` | 켜기 / 끄기 단축 (메뉴의 3번 / 4번) |
| `cache.json` | 목록·ISIN 매핑 캐시 (자동 생성, 지워도 무방) |
| `server.log` | 창 없는 실행용 로그 (자동 생성, 1MB 넘으면 시작 시 비움) |
| `android/` | 안드로이드 앱 (같은 `server.js`를 쓰는 WebView 앱) — [빌드 방법](https://github.com/tropical-love/iNAVnow/tree/main/android) |
| `tools/` | 앱 에셋·런처 아이콘 생성 스크립트 |

코드를 고치셨다면 실행 전에 `node test.js`로 회귀 검사를 돌려 보세요.
